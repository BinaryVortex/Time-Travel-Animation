# Time Travel Animation

A small interactive time-travel visual animation built using HTML, CSS and JavaScript.

![Demo Screenshot](./Screenshot%202024-08-21%20193517.png)

## Overview

This repository contains a lightweight front-end animation that simulates a "time travel" effect using HTML, CSS and vanilla JavaScript. It's intended as a visual demo and can be opened locally in your browser for quick viewing.

## Features

- Smooth time-travel animation with CSS transitions and JavaScript control
- Lightweight: no frameworks or build tools required
- Single-page demo (index.html) for quick preview and testing

## Demo / How to run

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Time-Travel-Animation.git

2. Open `index.html` in your browser (double-click or use your editor's preview). No server required.

   - Or from the command line (optional simple server):

     ```bash
     # Python 3
     python -m http.server 8000
     # then open http://localhost:8000 in your browser
     ```
